# Restore Python source-context behavior in Rust

Historical authority: Git `app/core/cli_tui.py::_expand_at_file_mentions` appended real bounded file bodies; `app/evidence/codegraph_slicer.py` discovered symbols from inspected files and unified-diff hunks and included indexed definition ranges plus one-hop neighbors. The current Rust source builder can miss leading/quoted/Unicode mentions, ignore mentions when explicit files exist, reduce a large function to ±3 matching lines, and silently substitute unrelated inventory after a missing mention.

Restore explicit `@file`, JSON-quoted paths and optional line ranges at the gateway grounding boundary; include mentioned files before inferred files even when `files_inspected` exists. Missing/traversal/escaping references fail before provider dispatch. Preserve typed public MCP argument/schema contracts. Add prepared read-only CodeGraph file/range queries, use actual indexed function ranges and bounded neighbor context, and restore inline definition/diff discovery. Keep all UTF-8 source and rendered context bytes bounded, report truncation visibly, and never claim missing/omitted source was read.

Ownership: context agent owns `context/source.rs`, `context/relevance.rs`, gateway grounding helpers, `storage/sql.rs` and `sql/codegraph_slicer.sql`; parent owns terminal input/HUD and adapter integration. No Python restoration, new dependencies or schema migration. Regression tests cover real quoted/Unicode and large late source, diff/file CodeGraph discovery, explicit mentions alongside inspected files, byte limits and escape/missing rejection. Run focused context/SQL tests and strict Clippy; root owns final canonical CI and installed consumer proof.

## Result and accepted integration extensions

- Gateway validates and canonicalizes actual attachments into `files_inspected` before registration/dispatch, so evidence hashing receives the actual mentioned paths even when another inspected file was already supplied. Quoted Unicode/punctuation/literal-colon names and explicit line ranges are preserved. Missing, traversal, escaping symlink and unterminated quoted attachments fail explicitly.
- File and unified-diff CodeGraph queries restore complete indexed definition ranges and one-hop metadata. Without an index, named late definitions are selected from actual source rather than a hard first-200-line prefix. Source rendering includes its headers in the UTF-8 byte budget; file reads are capped at 4 MiB/100,000 lines and explicit mentions retain the historical 8,000-byte per-file bound. `truncated` reports omitted context.
- A user literal matching the words `=== ACTIVE REGISTERED SKILLS` cannot hide an attachment. Only complete registered blocks matching the current known on-disk bodies are excluded from source selection; text before/after them remains. The same selection text feeds attachments, diff discovery and symbols. Original arguments still supply all instructions to the provider.
- Parent-approved gateway follow-through restored legacy engine aliases and the historical HTTP omitted-model default (`gpt-6.1-sol`), keeping the CLI omitted-model default unchanged. Invalid sandbox and file-valued workspace checks now run before a Running job can be registered.
- The backend worker owns bounded native `codex app-server --stdio` configuration effects. Gateway integrates explicit `codex-default` once before async admission, passes that same trusted resolution through execution, and preserves the raw requested alias separately from resolved/actual model identity. Explicit models bypass the probe. Gateway pre-dispatch/budget receipts use the backend's common trusted alias projector. No client-spoofable argument marker or new MCP field was added.
- Final current-source validation: 16 gateway tests, 11 context tests, 6 SQL tests and strict all-target/all-feature Clippy passed. The native-default integration test uses a controlled executable, proving one config probe for each synchronous/asynchronous alias dispatch, none for an explicit model, matching actual/concrete identity and preserved raw alias. These are controlled boundary tests, not a claim of real provider execution or final installed consumer parity.
